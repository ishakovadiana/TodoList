# ✅ Список дел с категориями

Веб-приложение для управления задачами с категориями и приоритетами.

## Функции
- Регистрация и вход
- Добавление/редактирование/удаление задач
- Категории: работа, личное, учеба, дом
- Приоритеты: высокий, средний, низкий
- Отметка о выполнении
- Дедлайны
- Поиск по названию
- Фильтр по категориям

## Запуск
```bash
pip install -r requirements.txt
python app.py
